# student-marks-system
## Overview
A Python-based application to manage student marks with:
- GUI (Tkinter)
- Web App (Flask)
- OOP design

## Features
- Add student marks
- Calculate total, average, grade
- Store data in CSV/Database

## Technologies
- Python
- Flask
- Tkinter
- SQLite

## Run Project
### GUI
python gui.py

### Web App
python app.py
